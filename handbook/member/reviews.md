# Reviews

When your work has arrived, open `#reviews` and use the panel there to post feedback.

## Write a useful review

- Say who did the work, and spell the name correctly
- Say which service it was
- Pick a rating that matches what actually happened
- Describe it in a respectful way

## Keep it public-safe

Anyone in the server can read a review. Leave out personal details, payment information, and notes that should stay inside your ticket.
