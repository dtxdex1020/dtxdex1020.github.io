# Applications

Staff and creative openings are posted in `#opportunities`.

## How to apply

Use the **Staff Application** or **Creative Application** button. The button opens a form.

In the form:

- Introduce yourself
- Say which role you want
- Explain experience that fits that role
- For creative roles, add links to work you have already made

Staff reply in a private ticket and tell you what happens next.

## While it is open

Do not file a second application for the same role while the first one is still in progress. Keep other people's application answers private, and do not paste them into public channels.
