# Taking Orders

## How clients open work

1. Client opens **`#order`**.
2. Client picks a service from **Choose a service**.
3. Client picks **PayPal** or **Robux**.
4. Client fills the form (budget, deadline, specifications, references).
5. A private ticket opens in that department's category.

Do not ask clients to type a department name into an old form. Send them back to `#order` if they open the wrong path.

## Claiming a ticket

- Claim work you can finish to the agreed quality.
- Read the full brief before quoting.
- If the brief is incomplete, ask focused questions instead of guessing.
- If the request is not your skill set, leave it for the right designer or ask staff to reassign.

## Custom vs package

| Path | Use when |
| --- | --- |
| `#order` custom ticket | Client needs something made or substantially changed for them |
| Package / marketplace listings | Ready-made product with fixed delivery details |

Do not turn a package listing into a full custom project inside the package flow without staff approval. Large changes belong in `#order`.
