# Delivery & Revisions

## Delivery checklist

Before you mark work complete:

1. Files match the agreed scope and formats
2. Payment has been confirmed
3. Delivery message is posted in the ticket with clear file links or attachments
4. Client knows how to open / use the files
5. Any leftover notes (source files, install steps) are in the ticket

## Licensing reminder for clients

Clients receive rights to use the delivered assets in their own community. A purchase does not allow reselling, leaking, redistributing, or sharing the assets with other communities unless Dex agrees in writing in the ticket.

## Revisions

- Honor the revision terms you wrote into the quote.
- Extra rounds beyond that quote need a new mini-quote.
- If the client rejects work that matches the agreed brief, escalate to high rank with the ticket evidence.

## Reviews

After a smooth delivery, clients can leave feedback in **`#reviews`**. Do not pressure anyone for a five-star rating. If a review is inaccurate or abusive, let support handle it.
