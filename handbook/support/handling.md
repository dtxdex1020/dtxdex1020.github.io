# Handling Tickets

## Start calmly

Open with a short, professional greeting and your role. Example pattern (use your own name):

> Hey, I am part of the Dex's Commissions support team. I will help you with this ticket today.

Ask what they need if the form answer is unclear.

## Keep it professional

- Do not sound rushed or dismissive.
- Ask clear questions when you need more detail.
- Guide the client to the right channel instead of forcing the wrong ticket type.

## Route correctly

| Situation | Route |
| --- | --- |
| New custom project | `#order` service picker |
| Account / Roblox link | `#verify` |
| Package / marketplace question | `#marketplace` or package forums, escalate listing issues |
| Staff or creative application | `#opportunities` application buttons |
| Order dispute after delivery | Stay in `#assistance`, gather evidence, escalate |
| Course access | https://discord.gg/DYxRPEGPF — if invite fails, ask Dex/high rank for a fresh one |

## Close properly

Before closing:

1. Confirm the issue is resolved or cleanly handed off.
2. Ask if they need anything else and give a short window to reply.
3. Close only when the next step is clear or the ticket is finished.

Use the bot close flow so transcripts are saved when available.
