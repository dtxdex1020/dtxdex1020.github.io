# CorePilot

**CorePilot AI Receptionist** — Phase 1 foundation (Next.js + TypeScript + Tailwind).

This app lives in the `corepilot/` folder so it does not overwrite the existing GitHub Pages site at the repo root.

## Quick start

```bash
cd corepilot
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | What it does                          |
| --------------- | ------------------------------------- |
| `npm run dev`   | Start local development server        |
| `npm run build` | Create a production build             |
| `npm run start` | Run the production build locally      |
| `npm run lint`  | Check code with ESLint                |
